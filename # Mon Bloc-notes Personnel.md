# Mon Bloc-notes Personnel

## Description

Mon Bloc-notes Personnel est un éditeur de texte conçu pour prendre des notes rapidement et les organiser facilement.

## Fonctionnalités

- Création et modification de notes
- Sauvegarde automatique
- Recherche dans les notes
- Plusieurs thèmes d'affichage
- Thème clair
- Thème sombre
- Interface simple et rapide

## Installation

1. Téléchargez le fichier ZIP.
2. Décompressez-le.
3. Lancez BZnotes.exe.
